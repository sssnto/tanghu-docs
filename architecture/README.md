```

│                        用户端 App                            │

│   Android (Kotlin)   │           iOS (Swift)                │
│   Jetpack Compose    │           SwiftUI                     │
│      MVVM            │            MVVM                       │
└──────────┬───────────┴──────────────┬───────────────────────┘
           │                          │
           ▼                          ▼
┌─────────────────────────────────────────────────────────────┐
│                     共享模块 (Common)                        │
│              DTO | API 接口 | 数据模型                        │
└─────────────────────────────────────────────────────────────┘
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│                      后端 API 服务                           │

           │
           ▼

```

## 2. Android 架构

### 目录结构

```
app/src/main/java/com/tanghu/app/
├── MainActivity.kt
├── data/                    # 数据层
│   ├── api/                 # Retrofit 接口
│   ├── model/              # 数据模型
│   └── repository/          # 仓库实现
├── domain/                  # 领域层
│   ├── model/              # 领域模型
│   └── usecase/            # 用例
└── ui/                     # 表现层
    ├── screens/            # 页面
    ├── components/         # 组件
    ├── viewmodel/          # ViewModel
    └── theme/              # 主题
```

### 依赖关系

```
UI → ViewModel → UseCase → Repository → DataSource
```

## 3. iOS 架构

### 目录结构

```
TangHuApp/
├── TangHuAppApp.swift      # 入口
├── ContentView.swift       # 主视图
├── Views/                  # 页面视图
│   ├── HomeView.swift
│   ├── RecordView.swift
│   ├── TrendView.swift
│   └── ProfileView.swift
├── ViewModels/             # ViewModel
├── Models/                 # 数据模型
├── Services/               # API 服务
└── Extensions/             # 扩展
```

## 4. 核心模块

### 血糖记录模块

- 记录血糖值、时间、类型
- 本地缓存 + 服务端同步
- 数据校验（合理范围判断）

### 趋势分析模块

- 7天/30天/90天趋势展示
- 统计数据计算（均值、达标率）
- 图表可视化

### 用户模块

- 用户资料管理
- 目标血糖设置
- 用药提醒配置
